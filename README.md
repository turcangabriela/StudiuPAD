# StudiuPAD
## Descrierea proiectului

Acest proiect prezintă un studiu despre aplicația desktop Microsoft Word, în care sunt descrise scopul acesteia, cerințele funcționale și non-funcționale.

## Scopul aplicației

Microsoft Word este o aplicație desktop utilizată pentru crearea, editarea și formatarea documentelor text. Aceasta oferă utilizatorilor instrumentele necesare pentru realizarea diferitelor tipuri de documente.

## Cerințe funcționale

- Crearea documentelor noi.
- Introducerea și editarea textului.
- Formatarea textului prin schimbarea fontului, dimensiunii și culorii.
- Inserarea imaginilor și tabelelor.
- Salvarea și deschiderea documentelor.

## Cerințe non-funcționale

- Interfață simplă și ușor de utilizat.
- Funcționare stabilă, fără blocări frecvente.
- Timp de răspuns cât mai scurt.
- Protecția documentelor și a informațiilor utilizatorului.
- Compatibilitate cu sistemul de operare.
